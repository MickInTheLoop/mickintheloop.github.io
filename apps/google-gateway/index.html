Homelab Mail Gateway

A private integration for selected Gmail tasks with an AI assistant.

This application is operated by MickInTheLoop for personal use. It supports approved correspondence research, original email and attachment export, draft management, custom labels and stars.

What it can do

  • Search Gmail and read matching messages, headers and conversations within an approved task.
  • Export original email and download attachments for preservation.
  • Create, read, update and delete drafts, including replies in a conversation.
  • Organise mail with custom user labels and stars.

How access is controlled

Each connected project requires its own approval. Mailbox investigations additionally require a task approval bounded by account, purpose, capabilities, searches and time or session.

Google authorisation uses gmail.modify, which permits more actions than the gateway exposes. The gateway does not expose sending, forwarding, archiving, deletion of received or sent email, Trash, Spam, read-state changes or account settings. The owner reviews drafts and personally presses Send in Gmail.

Application information, not mailbox access

This website does not provide access to the gateway or a mailbox. Only Gmail is implemented; Calendar and Drive access are not enabled.
