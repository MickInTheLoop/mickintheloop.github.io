# MickInTheLoop personal information site

Static HTML/CSS for the personal GitHub Pages site and Homelab Mail Gateway information pages.

The website does not run the gateway or authenticate Google accounts. Do not add credentials, private correspondence, internal deployment details or private repository history.

- `/apps/google-gateway/` — application overview
- `/apps/google-gateway/privacy.html` — privacy policy
- `/apps/google-gateway/terms.html` — terms of use
